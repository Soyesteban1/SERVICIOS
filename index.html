// 03 — Sobre mí

El puente software
el el hardware mundo físico.

Soy Ingeniero Mecatrónico con sólida experiencia en Desarrollo Full Stack y Diseño de Hardware. Mi perfil es genuinamente híbrido: puedo escribir el algoritmo de control y fabricar el dispositivo físico que lo ejecuta.

Trabajo con con diferentes stacks de tecnologia para construir soluciones de software robustas, y con SolidWorks e impresión 3D para materializar ideas en prototipos funcionales. Configuro entornos Linux y mantengo flujos de trabajo profesionales con Git.

Esa capacidad de moverme entre el mundo digital y el físico me permite entender los proyectos de manera integral: el hardware que toca el código, y el código que controla el hardware.
